# ModelDefteri · ML Deney Günlüğü
React + TypeScript + Vite + Tailwind CSS ile yazılmış, makine öğrenmesi deneylerini kaydedip karşılaştıran uygulama.
CRUD: Ekle · Listele (arama + filtre + liderlik tablosu) · Güncelle · Sil. Veriler LocalStorage'da tutulur.

## Çalıştırma
npm install && npm run dev

## Yayınlama (Netlify)
Build command: `npm run dev`
